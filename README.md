# us-trading

KIS 기반 미국주식 + Upbit 크립토 자동매매 워크스페이스 (backend Express + frontend Next.js + mcp-worker Vercel 서버리스).

## 실데이터 원칙

화면의 모든 숫자는 실측이다. KIS 키가 없으면 미국주식 계좌/포지션/주문만
모의(백엔드 응답에 `mock: true`)이고, 시세(Yahoo Finance 지연)·뉴스(Google
News RSS)·크립토(Upbit)·파이프라인 지표는 전부 실데이터다. 배포된 대시보드는
`/api/backend/*` 읽기 전용 프록시로 Railway 백엔드를 부르며, 토큰이 없으면
"백엔드 미연결"을 그대로 보여준다 — 목 엔진으로 대체하지 않는다.

## 지표가 아니라 모델

RSI 같은 장난감 지표는 결정 경로 어디에도 없다. 시그널·스캐너·ML 피처·
파이프라인 알파·MCP 워커 리포트가 쓰는 것은 **HMM 레짐 belief**(3상태,
포워드 필터 P(Z_t|Y_1:t)), **GARCH(1,1) 조건부 변동성**(역변동성 가중·신뢰도),
**시계열 모멘텀 팩터**, **Kelly 사이징**, **블록 부트스트랩 유의성**뿐이다.
최종 결정은 그 위에서 오피스(모델들의 대화)가 내린다 — `docs/office-loop.md`.

## 백테스트 비용 모델

모든 백테스트 경로(backend `/api/crypto/backtest`, `/api/ml/*`, `/api/quant/report`,
frontend `/crypto`·`/lab`·`/quant`의 브라우저 계산, Vercel MCP 워커의
`upbit_backtest_report`)는 **수수료 0.05% + 슬리피지 0.05%/편도**를 턴오버에
부과한다 (`DEFAULT_COSTS`, `backend/src/crypto/backtest.ts`). 종료 시점에 열린
포지션의 청산 비용도 차감하고, `costDragPct`(무비용 대비 비용이 갉아먹은 %p)를
지표로 노출한다. 비용 없는 숫자는 상한선일 뿐이라는 원칙.

## 페이퍼 모드

`CRYPTO_TRADE=true`가 기본값 — 크립토 데스크는 시작하자마자 **페이퍼 장부**로
라이브 기록을 쌓는다 (실주문은 여전히 `CRYPTO_TRADE_ALLOW_REAL=true` + Upbit 키
둘 다 없으면 불가능). 체결은 슬리피지 반영 가격 + 수수료 차감으로 기록되고,
상태는 `backend/data/crypto-paper.json`(현금/포지션/주문), 에쿼티 스냅샷은
`backend/data/crypto-paper-equity.jsonl`(시간당 1줄)에 저장되어 재시작을
견딘다. 조회: `GET /api/crypto/status`(paperSince 포함),
`GET /api/crypto/paper/equity`.

## 알트코인 스캐너

`/scanner` 페이지 + `GET /api/crypto/scanner` — 업비트 KRW 전 마켓(~287개) 중
24h 거래대금 상위 30개를 스캔해 **위험조정 모멘텀(mom20/vol20)** 으로 랭킹하고,
추세 필터(종가>MA20) 통과 + 양의 점수 상위 5개를 역변동성 가중(코인당 25% 상한)
으로 로테이션 타깃을 만든다. 자격 코인이 없으면 100% 현금이 정답이고 그대로
반환한다.

- `GET /api/crypto/scanner/backtest` — 같은 규칙의 주 1회 리밸런스 백테스트
  (비용 반영, BTC 보유·동일가중 벤치마크, 블록 부트스트랩 p-값 +
  **유니버스 크기만큼 Bonferroni 다중검정 보정**). 스캔 자체가 N번의 암묵적
  검정이라는 사실을 숫자로 노출한다.
- `POST /api/crypto/scanner/rotate` — 페이퍼 장부를 타깃 비중으로 로테이션.
  **페이퍼 전용** — 실주문 모드에서는 거부. `CRYPTO_SCANNER=true`면 24h마다
  자동 로테이션.

이 모드가 극대화하는 것은 "비용 차감 후 위험조정 기대수익"이라는 시도이지
수익 자체가 아니다 — 백테스트는 인샘플 상한선이고, 판단은 페이퍼 장부의
실기록이 한다.

## 통합 제어 평면 (Command Center)

스캐너·오피스·진화·파이프라인 신호는 더 이상 장부를 각자 회전시키지 않는다.
전부 **제안**만 내고, 중재기가 엔진 가중 × 확신도로 하나의 목표 포트폴리오를
만들어 제약(종목 상한·총노출·현금 하한·최소 회전·집행 간격·킬스위치)을 지난 뒤
오토파일럿이면 집행, 아니면 운영자 승인을 기다린다. 어느 엔진이 돈을 벌었는지는
매일 실현 수익으로 귀속되어 가중치가 스스로 움직인다. 대시보드 홈이 그 화면이다.
→ `docs/control-plane.md`

## 2026-09-02 변경 요약

- **전략 페이지·OU/HJB 전략 삭제.** 매매 결정은 오피스 협의와 파이프라인 신호에서만 나온다.
- **가짜 미국주식 포지션 제거.** 보유종목·대시보드는 `/api/account/holdings` 실기록(크립토 페이퍼 장부 + 미국 장부 + Yahoo 환율)만 보여준다.
- **계정·금고.** 로그인 후 Upbit/KIS 키를 AES-256-GCM으로 서버에 저장 — `docs/accounts.md`.
- **증권 오피스 9역할 플로어.** 차트·뉴스·수급·매크로 → 퀀트 ⇄ 리스크(검토) → 리밸런스 ⇄ 레드팀(검토) → 위원장. `docs/office-loop.md`.
- **진화 캠페인.** 전략 유전자 개체군이 본 적 없는 60일 실캔들로 시험을 보고, 서로 자본을 위탁하고, 성과 낸 개체는 PyGAD로 복제되고, 굶주리거나 도태된 개체는 죽는다. Handsel 오피스는 lineage mandate·Automaton으로 같은 원리. `/evolution`, `docs/evolution.md`.
- **Self-healing 수집 감독자.** Yahoo·Upbit·뉴스 수집을 한 감독자가 돌린다 — 지수 백오프 재시도, 회복 시 실제 백필(1분봉 재생·RSS 재수집), BREAK NODE 장애 주입, 오케스트레이터 로그. `docs/self-healing.md`.
- **파이프라인 모니터.** `/pipeline`이 릴 수준의 실시간 모니터 — 스테이지 열, 빛 하나 = 실제 마이크로배치, 깊이 블러, 노드 상세·라이브 행.
- **타임락 eta 캘린더 — 크립토의 "예정 공시".** 거버넌스 타임락이 큐에 넣은 실행을 **미래 시각과 함께** 온체인에 공표하는 것을 읽는다. Compound식(`QueueTransaction`의 `signature`가 사람이 읽는 문장)과 OZ식(`getTimestamp(id)`로 eta·완료 확인) 둘 다. 타임락 주소는 손으로 관리하지 않고 토큰 `owner()`에서 **발견**한다. 그 결과 owner를 타임락(예고 있음, 벌점 없음)·EOA(예고 없음, ×0.7)·미확인 컨트랙트(×0.85)로 구분하니 **같은 `mint` 진입점이 T에서는 ×0.5, SOPH에서는 ×0.637**로 갈린다. 실측: ENA는 1일 지연 타임락에 살아있는 예약 31건. topic0는 실물 로그로 검증하고 테스트에 그 로그를 붙여 고정했다. `docs/onchain-contracts.md`.
- **컨트랙트 분석 — 크립토의 "공시".** 뉴스 헤드라인의 사후 감성 대신 **배포된 바이트코드**를 읽는다. 키 없는 공개 RPC로 `eth_getCode` → 디스패처의 PUSH4 셀렉터에서 `mint`·`pause`·`upgradeTo`·블랙리스트·역할 권한을 찾고, EIP-1967 프록시는 구현까지 따라간다. 리스크 총괄이 high면 비중 ×0.5, medium이면 ×0.75로 깎고 회의록에 리비전으로 남긴다 — 상관·VaR과 달리 **가격이 아닌 근거**다. 실측: ANKR clean, SOPH medium, T·FLOCK·UNI·ONDO high(mint), ARB는 업그레이드 가능 프록시, BTC·ETH·SOL은 자체 체인이라 해당 없음. `docs/onchain-contracts.md`.
- **데이터 스누핑 검정 + 디플레이티드 샤프.** `arch`의 Hansen SPA/StepM을 파이썬 사이드카로 붙여 "유니버스 최고가 BTC 보유를 이긴 게 실력인가 N번 본 결과인가"에 p값으로 답한다 — 실측 **개별 코인 p=0.947, 로테이션 규칙 p=0.332, 양쪽 다 우월 후보 없음**(350일). 규칙은 파라미터 격자 9개 전부에서 연 −5~−45%이고, 파괴적인 축은 topK가 아니라 리밸런스 주기(7일 −42% vs 30일 −10%)다. 진화 챔피언 Sharpe는 시행 수로 깎은 DSR로 기록된다. arch가 없으면 p값을 지어내지 않고 "못 쟀다"로 답한다. `/scanner`, `/evolution`, `docs/library-survey.md`.
- **기존 퀀트 라이브러리 조사.** 직접 짠 3,000줄(HMM·GARCH·백테스트·튜너·Upbit 클라이언트)에 대응하는 성숙한 라이브러리를 훑고 무엇을 채택할지 정리했다 — ccxt(JS, 즉시), arch의 SPA 다중비교 검정과 Deflated Sharpe(우리가 계속 틀리는 "우위가 진짜인가"에 정확히 대응), skfolio/Riskfolio, Optuna. 에이전트 층은 대체 대상이 아니다. `docs/library-survey.md`.
- **증권 오피스가 꼭대기를 사던 구조를 고쳤다.** 후보가 스캐너 상위 5(20일 모멘텀 1등)가 아니라 메이저 + 보유분 + 60일 위험조정 상위이고, 20일 +40% 과열은 제외·+25%는 절반, "포지션 없음"이 정식 답. 확신도는 통과 단계 비율(항상 1.0)이 아니라 퀀트 데스크의 t값(μ̂/σ̂·√n)에서 나온다. 펌핑을 묘사하는 헤드라인은 강세 근거에서 뺀다. `docs/office-loop.md`.
- **진화 시험지가 세대마다 다르다.** 캔들 1년치에서 세대마다 60일 창을 무작위로 뽑아(훈련 80일 뒤, 직전 창과 30일 이상 떨어지게) 시험을 본다. HMM은 창 앞까지만 적합. 실전 타깃은 시험 창이 아니라 최신 데이터에서 계산. 같은 창의 재채점이 아니라 다른 창들을 연속으로 통과해야 살아남는다. `docs/evolution.md`.
- **벤치마크 + 테스트.** 홈에 "장부 vs BTC 보유 vs 유니버스 동일비중(기준 시점 바스켓 고정)"과 두 초과수익이 5분 마크마다 실시세로 나온다 — 결정이 뭔가를 더했는지 답하는 유일한 줄. 백엔드에 vitest 시작(협의회·벤치마크·회전 상한·env 파서), GitHub Actions CI. `docs/control-plane.md`.
- **정족수제 vs 비례제.** 협의회 표결이 두 방식 중 하나로 돈다 — 정족수제(제안 매니저 2명 이상, 기본)와 비례제(standing 지분 × 확신도의 합이 문턱 이상; standing이 높은 매니저는 혼자서도 산다). 집행되지 않는 쪽은 매 중재마다 그림자로 함께 돌아 결정에 남고, 두 방식의 포트폴리오가 5분 마크로 각각 채점된다. 홈에서 라디오 하나로 전환. 권고와 전환 규칙은 `docs/control-plane.md`.
- **알트코인은 자산, 스캐너는 도구가 아니다.** 메이저 + 24h 거래대금 상위 30 + 보유분이 투자 유니버스이고(30분 갱신), 데스크가 그 전체의 시세·호가·뉴스를 파이프라인에 넣어 신호 엔진도 알트를 제안한다. 오피스·진화는 이미 같은 유니버스를 쓴다. 스캐너 엔진·자동 로테이션은 없어졌고 `/scanner`는 "투자 유니버스" 페이지가 됐다.
- **누를 것 없음 + 직관대로 움직이는 컨트롤.** 보류 결정은 자동 모드에서 "N분 뒤 자동 집행"만 보이고, 집행 모드는 [자동|승인] 라디오, 엔진 참여는 스위치다. `/pipeline`의 항상 실패하던 자동매매 스위치는 상태 카드로, 데스크의 신호 직접 집행은 닫혔다. 색상 기본은 한국식(상승 빨강)이고 선택은 브라우저에 남는다.
- **5분 귀속·결정 타율·이력.** 엔진 귀속이 일봉이 아니라 5분 마크(실시세)로 돈다. 집행된 결정마다 다음 집행까지의 실현 결과와 타율이 기록되어 홈에 보인다. 이미 보유한 시장은 제안 매니저 하나만 지지해도 유지되어(정족수는 진입 때만) 매시간 SOL·ETH를 사고팔던 flip-flop이 사라진다. 평단 반올림 버그(BONK 평단 0) 수정. 원인 분석은 `docs/control-plane.md`.
- **매니지먼트 협의회.** 스캐너·오피스·진화·신호 총괄 4명이 제안하고 센티먼트·리스크 총괄이 지지·반대·거부권을 낸다. 3라운드(입장 → 반대에 대한 수정 → 표결)를 거쳐 제안 매니저 2명 이상이 지지한 시장만 채택된다 — 신호만 보고 매수하지 않는다. 협의록은 결정에 남는다. `docs/control-plane.md`.
- **페이퍼 장부 초기화 + 잔거래 억제.** `POST /api/crypto/paper/reset`(운영자 토큰)이 포지션·주문·에쿼티 기록을 지우고 ₩10,000,000에서 다시 시작한다. 제어 평면 기본 정책이 집행 간격 60분·최소 회전 8%로 올라가 잔거래 오염을 막는다.
- **무인 운행.** 스캐너·오피스·진화·신호 루프 전부 기본 ON, 중재·승인·페이퍼 집행 자동, 보류된 결정은 5분 스케줄러가 간격이 지나면 집행, 엔진 가중치는 매일 스스로. 오토파일럿은 매 부팅 env 기본값(true). 멈추는 손은 홈의 "자동 운행 정지" 하나 — 재배포에도 유지된다. `docs/control-plane.md`.
- **알트 스캐너 화면이 백엔드 스캔을 읽는다.** 브라우저에서 Upbit `market/all`·`ticker`를 직접 부르며 스캔하던 것이 실패의 원인 — 이제 `/api/crypto/scanner`(공유 캔들 저장소·캐시)와 백테스트를 읽고, "지금 로테이션"(로그인)이 제어 평면에 제안한다. 크립토 페이지 시세도 백엔드 `/crypto/quotes`를 거친다. 브라우저에 Upbit 직접 호출은 남아 있지 않다.
- **로컬 오피스 협의.** `OFFICE_MODE=local`(기본)이면 9역할 플로어가 Handsel 에스크로 없이 백엔드 안에서 돈다 — 각 역할이 실도구를 직접 부르고, 리스크·레드팀 검토가 REVISE 라운드를 돌리고, 위원장이 JSON 결정을 낸다. `/office`에서 "지금 협의". `docs/office-loop.md`.
- **에이전트 = 오피스.** 진화 개체가 실제 MCP 데스크(차트·뉴스·수급·매크로·리스크·Exa 웹)를 빌려 보고서를 읽고 스킬로 타깃을 고친다. 임대료는 자본에서 나가고, 도구를 잘못 읽으면 굶는다. `docs/evolution.md`.
- **통합 제어 평면.** 스캐너·오피스·진화·파이프라인 신호가 각자 장부를 덮어쓰던 것을 끝냈다. 엔진은 제안만 내고, 중재기가 가중 × 확신도로 하나의 목표를 만들어 제약을 지나 오토파일럿/승인으로 집행하며, 매일 실현 수익으로 엔진 가중치가 움직인다. 대시보드 홈 = Command Center. `docs/control-plane.md`.
- **Upbit 캔들 공유 저장소 + 전역 속도 제한.** 모든 일봉은 백엔드 `candle-store`(단일 비행·오래된 값 폴백) 하나에서 나오고, Upbit 호출은 초당 8회 토큰 버킷을 지난다. 브라우저는 Upbit를 직접 부르지 않고 `/crypto/candles/:market`을 쓴다 — "캔들을 못 불러오는" 오류의 원인이던 탭마다의 직접 호출·429가 사라진다.
- **$100 자리표시 시세 제거.** Yahoo가 아직 채우지 않은 종목은 `503 QUOTE_PENDING`으로 답하고 관심종목 카드는 "시세 미수신"을 보여준다 — 가짜 숫자를 만들어 주지 않는다.
